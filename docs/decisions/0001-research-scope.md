# 1. Publish a focused research artifact

Status: accepted for the initial repository setup.

This repository contains the bounded-count identification result, its proof
sources, exact reproductions and stated limitations. It is deliberately small
enough for another person to inspect. The mathematical statement concerns a
specified model; it does not establish laboratory performance or priority.

We use a dependency-free Python core and an optional, separately pinned formal
toolchain. Code and documentation are licensed for reuse, while third-party
notices retain their own terms. A process disclosure is separate from authorship
metadata. The maintainer is a human using a public pseudonym.

Package-registry publication, growth automation, promotional posts, fabricated
badges and unsupported claims of completeness are outside this scope. Security
and CI settings are recorded as observed states, not assumed successful because
a command was issued.
